# 童话异想拼贴 · Storybook Surreal Collage

一个把真实照片改造成童话绘本感超现实剪纸拼贴的 AI agent skill。

人物、前景和未编辑区域保留原始自然色与摄影质感；天空或背景被组织成远、中、近三层平涂剪纸色形；画面只允许出现一个源自原图或场景典故的“不可能巨物”。

> 真实留色、平涂梦境、一物不对劲、元素源于图、色从图中来。

## 适合什么

- 把旅行照、人像、城市或风景照做成明亮的童话异想拼贴
- 保留人物肤色、服装和前景，只改天空或指定背景
- 制作适合短视频、社交媒体封面与图文内容的视觉作品
- 避免默认红日、蓝天、鲸鱼等模板化元素，让巨物和配色真正来自原图

## 安装

将整个 `storybook-surreal-collage` 文件夹复制到所用 agent 的 skills 目录。

### 一句话安装并使用

把下面这句话和需要处理的照片一起发给支持安装 GitHub skill 的 agent：

```text

```

安装完成后，也可以直接说：

```text
使用 $storybook-surreal-collage 处理这张图片。
```

## 视觉规则

1. **真实留色**：人物、前景、服装、地景和未编辑区域默认保留原始自然色与摄影纹理。
2. **三层天空**：远层保留呼吸区，中层使用嵌套剪纸云带，近层色带衔接山脊、建筑或海平线。
3. **一物不对劲**：全图只放一个不可能巨物，并能说明它来自原图元素或当地典故。
4. **色从图中来**：色形从照片已有色提纯、互补或情绪反转，不套用固定彩虹模板。
5. **平涂无渐变**：剪纸区域保持哑光平涂，不使用立体阴影或渐变。
6. **克制装饰**：小元素成组、有大小梯度并沿弧线分布，同时保留 25–40% 安静区域。

## 相比原项目修改了什么

本项目基于 [`2998980-hue/surreal-pop-collage`](https://github.com/2998980-hue/surreal-pop-collage) 修改，保留了原项目“一物不对劲、元素源于图、平涂无渐变”的核心创作方法。

这个版本主要进行了以下调整：

- 将默认的黑白现实锚改为**原色摄影现实锚**；只有用户明确要求时才允许去色。
- 将天空从简单背景色块扩展为**远、中、近三层剪纸结构**。
- 增加 25–40% 呼吸区、鸟群、涂鸦和星点的数量预算，控制画面节奏。
- 增加“只改天空/背景”的**局部编辑模式**，锁定人物身份、边缘、构图、纹理和原始颜色。
- 增加针对天空过空、前景误变黑白、编辑越界等问题的定向纠偏规则。
- 更新 Prompt 编译器和交付前质量门，使结果更适合明亮、温暖的自媒体视觉内容。

更详细的来源与改动说明见 [`NOTICE.md`](NOTICE.md)。
