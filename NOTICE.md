## Summary of modifications

- Renamed and repositioned the skill as a storybook-style surreal collage workflow.
- Replaced the default black-and-white reality anchor with preserved natural photo color.
- Added a three-layer paper-cut sky system with explicit breathing-space rules.
- Added bounded decoration counts and source-derived palette constraints.
- Added partial-edit mode with identity, edge, composition, texture, and color locks.
- Added targeted recovery rules for empty skies, accidental desaturation, and edit spillover.
- Updated the prompt compiler and quality checklist for the color-preserving workflow.

This repository is an independent derivative and is not an official release of
the upstream author.
